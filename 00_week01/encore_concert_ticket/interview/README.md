# เอกสารเก็บความต้องการ ENCORE

ชุดเอกสารหลักสำหรับโครงการจองบัตรคอนเสิร์ต ตั้งแต่ความต้องการผู้ใช้จนถึงกติกาที่ใช้พัฒนาและทดสอบ

| เอกสาร | เนื้อหา |
| --- | --- |
| [บันทึกสัมภาษณ์](INTERVIEW.md) | 24 คำถาม–คำตอบ ครบ 12 หัวข้อ |
| [สรุปขอบเขตและกติกา](OWNER-ANSWERS.md) | ข้อสรุป 12 หมวด พร้อมอ้างกลับไปยังคำถามและข้อกำหนด |
| [ดัชนีคำถาม](interview-index.json) | INT-001–024 พร้อมหัวข้อและรหัสข้อกำหนด |

## ลำดับการอ่าน

1. บันทึกสัมภาษณ์ → สรุปขอบเขตและกติกา
2. [User Stories](../USER-STORIES.md) → [Requirements](../REQUIREMENTS.md)
3. [การออกแบบ](../DESIGN.md) → [ใบสั่งพัฒนา](../BUILD-PROMPT.md)
4. [ข้อมูลทดสอบ](../TEST-DATA.md) → [แผนทดสอบ](../TEST-PLAN.md) → [รายงานผล](../e2e/index.html)

## ขอบเขตการเชื่อมต่อ

ตรวจสมาชิกจากข้อมูลภายในระบบ การชำระและคืนเงินใช้ผู้ให้บริการทดสอบ และจัดส่งอีเมลผ่านกล่องภายในระบบ การเชื่อมฐานสมาชิกภายนอก ผู้ให้บริการรับเงินจริง และ SMTP เป็นงานเชื่อมต่อเพิ่มเติมนอกขอบเขตส่งมอบนี้
