# ENCORE — ระบบจองบัตรคอนเสิร์ต

ระบบจองบัตรแบบระบุที่นั่ง รองรับรอบสมาชิกและรอบบุคคลทั่วไป การเข้าคิว ตรวจหมายเลขสมาชิก เลือกที่นั่ง กรอกผู้ถือบัตร ชำระเงิน ออก E-Ticket QR และจัดส่งรายละเอียดเข้ากล่องอีเมลของผู้ซื้อ พร้อมงานหลังบ้าน คืนเงิน และตรวจบัตรเข้างาน

## เปิดใช้งาน

เปิด Docker Desktop แล้วรันในโฟลเดอร์โครงการ:

```sh
docker compose up --build
```

เข้าใช้งานที่ **http://localhost:4310** ครั้งถัดไปใช้ `docker compose up` ได้เลย โดยไม่ต้องติดตั้ง Node.js บนเครื่อง หากต้องการรันเบื้องหลัง:

```sh
docker compose up -d --build --wait
```

หยุดด้วย `Ctrl+C` หรือ `docker compose down` ข้อมูลเก็บใน named volume `encore-data` และกลับมาเมื่อเปิดใหม่ คำสั่ง `docker compose down --volumes` ใช้ล้างข้อมูลเพื่อเริ่มใหม่เท่านั้น

หากพอร์ตไม่ว่าง ใช้ `ENCORE_PORT=4315 docker compose up --build` แล้วเปิดพอร์ต 4315 หรือตั้งค่าใน `.env` ตาม `.env.example`

ค่าเริ่มต้นใช้นาฬิกาทดสอบวันที่ 6 พฤศจิกายน 2569 เวลา 10:00 น. ไทย และเดินตามเวลาที่เซิร์ฟเวอร์ทำงาน ทุกครั้งที่เริ่มเซิร์ฟเวอร์จะเริ่มจากเวลานี้ หากตั้ง `LIVE_CLOCK=1` จะใช้เวลาปัจจุบัน สถานะรอบขายจึงอาจต่างกัน

### เปิดด้วย Node.js

ใช้ Node.js 22.13 ขึ้นไป:

```sh
npm ci
npm start
```

เปิดที่พอร์ต 4310 เช่นเดียวกัน ฐานข้อมูลอยู่ที่ `web/data/encore-v2.sqlite` ซึ่งเป็นชื่อไฟล์ภายในระบบ ส่วน Docker ใช้ข้อมูลใน volume ของตนเอง อย่าเปิดสองวิธีพร้อมกันที่พอร์ตเดียวกัน

## ขอบเขตการเชื่อมต่อ

ตรวจสมาชิกจากฐานข้อมูลภายใน รองรับ QR / 7-Eleven / Credit Card / Alipay ผ่านผู้ให้บริการทดสอบ โดยไม่เรียกเก็บเงินจริงและไม่รับข้อมูลบัตรเครดิตจริง QR ชำระใช้รหัส `ENCORE-DEMO-PAY` ส่วนเลขอ้างอิง 7-Eleven มีอายุเท่ารายการจอง จึงใช้จ่ายภายนอกไม่ได้

E-Ticket มี QR ที่ถอดรหัสได้จริง พร้อมชื่อผู้ถือภายนอก QR ระบบสร้างอีเมลถึงผู้ซื้อในกล่องภายในเว็บไซต์และดาวน์โหลด `.eml` พร้อมภาพ QR ได้ การเชื่อมฐานสมาชิกภายนอก ผู้ให้บริการรับเงินจริง และ SMTP อยู่นอกขอบเขตส่งมอบนี้

```sh
npm ci
npx playwright install chromium
npm run test:all
```

```sh
npm run lab:all
npm run lab:validate
```

คำสั่งนี้รันโหมดปกติและโหมดฝังข้อบกพร่องโดยใช้แผนและค่าคาดหวังเดียวกัน แล้วสร้างรายงานเปรียบเทียบ ต้องติดตั้ง `ffmpeg` เพื่อสร้าง GIF จากวิดีโอ ไม่จำเป็นต้องติดตั้งเพื่อเปิดเว็บด้วย Docker ตามปกติ `BUG_MODE` มีผลเฉพาะเมื่อ `TEST_MODE=1` และค่าเริ่มต้นเป็นปิด
