# C4 — ชำระเงิน ออกบัตร และอีเมลทดลอง

ผู้สำรวจ: agent `explore_c1` รับ charter C4 ใน wave ถัดจาก C1 โดยใช้ server และ browser context คนละชุดกับ C1 หลักฐาน C1 ถูกเก็บไว้ไม่แก้ไข รายงาน C4 ไม่อ้างว่าเป็น agent คนละตัวกับ C1

- URL เฉพาะ C4: `http://127.0.0.1:4344` ฐานข้อมูล in-memory แยกจากทุก charter
- เริ่ม `2026-11-06T11:14:37.813Z` จบ `2026-11-06T11:14:41.722Z` (เวลาของ automated probes และ UI journey ไม่รวมการอ่านเอกสาร/เขียนรายงาน)
- อ่านข้อกำหนดและ TEST-DATA ก่อนลงมือ ใช้ SPEC/ASSETS เป็นคำอ้างของผู้สร้าง ไม่ใช้เป็น expected หลัก
- ไม่เปิด runtime source หรือ `web/BUGS.md`; reset/clock เปลี่ยนเฉพาะ server 4344 ตามสิทธิ์ของ charter C4 ไม่แตะ 4310 หรือ server อื่น

## ทำซ้ำและขอบเขต

```sh
node exploration/lab8/c4/explore.mjs
```

สคริปต์อ่าน URL ของ C4 จาก ENVIRONMENT.json และยืนยันว่าเป็น 4344 ก่อนทำรายการ ใช้ reset ก่อนแต่ละกรณีและเลื่อนเวลาเฉพาะสถานการณ์ค่าขอบ ผลท้ายรอบกลับมาเวลาเริ่มต้นและมีตั๋ว AURORA C01 หนึ่งใบจาก UI journey

ไม่พบ runtime defect ใน 11 สถานการณ์นี้ แต่ไม่ได้ทดสอบผู้ให้บริการเงินจริง SMTP จริง เลขบัตรเครดิตจริง แอป Alipay จริง หรือการชำระเคาน์เตอร์จริง ความถูกต้องของการคืนเงินหลังถูกขายที่เดิมให้คนอื่นและเหตุการณ์ crash/disk-full ต้องใช้กรณีเฉพาะเพิ่มเติม ไม่ถือว่าการผ่าน callback boundary เท่ากับรับรองทุก race
