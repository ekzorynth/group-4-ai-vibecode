## สิ่งที่คงเดิมและสิ่งที่เปลี่ยน

- คัดลอกสคริปต์เดิมของ C1/C4 มาไว้ replay เปลี่ยนเฉพาะเส้นทาง output ไม่เปลี่ยนข้อมูล expected หรือ assertion ตรวจเปรียบเทียบข้อความสคริปต์แล้ว
- reset เฉพาะ 4341 เพื่อปลด lockout เก่าก่อนเริ่ม C1 และ 4344 ก่อน C4 โดย token ของโลกทดสอบ บันทึกใน [agent-c1-resets.json](agent-c1-resets.json) ไม่แตะโลกของ agent อื่นหรือพอร์ต 4310
- C4 ยังมี reset/clock เฉพาะโลกตนระหว่างกรณีเหมือนรอบเดิม บันทึก HTTP ทุกครั้งใน replay/c4/http-evidence.json
- ผลการตรวจไม่เปลี่ยน: C1 ทั้ง 9 และ C4 ทั้ง 11 ผ่านเหมือนเดิม สิ่งที่เปลี่ยนคือ timestamp รหัสสุ่มคำสั่งซื้อ/payment/ticket และไฟล์ภาพจากการรันครั้งใหม่
- ไฟล์หลักฐาน C1/C4/C7 เดิม 23 ไฟล์ตรวจ SHA-256 เทียบก่อนเริ่ม replay แล้วตรงกันทั้งหมด ดู [digest ของต้นฉบับ](agent-c1-original-digests.json)
- ไม่อ่าน runtime source หรือ web/BUGS.md ระหว่าง replay ไม่ใช้ผลหน้าจอมาเปลี่ยนคำตอบ expected
