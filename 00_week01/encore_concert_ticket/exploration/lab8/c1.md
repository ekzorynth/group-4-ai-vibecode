ผู้สำรวจ: agent `explore_c1` แยกจากผู้พัฒนาหลักและ charter อื่น ข้อมูลนี้มาจากการสำรวจแบบ black-box รอบ LAB 8 ไม่ได้คัดผล 86 ข้อเดิมมาเป็นผลสำรวจรอบนี้

- Server เฉพาะ: `http://127.0.0.1:4341` ฐานข้อมูล in-memory ของ C1 เท่านั้น
- เวลาเริ่ม probe: `2026-11-06T11:11:30.170Z`
- เวลาจบ probe: `2026-11-06T11:11:31.488Z`
- อ่านก่อนสำรวจ: `REQUIREMENTS.md`, `TEST-DATA.md`, `web/SPEC.md`, `web/ASSETS.md`

## สิ่งที่พบและส่งต่อ

1. **เอกสาร SPEC ไม่สอดคล้องกันเล็กน้อย (P3):** บรรทัด implementation record ตอนต้นอ้างแสดงสองรอบ แต่ D และส่วนล่าสุดของ SPEC ระบุแยกตามบัญชี ระบบที่ตรวจทำตาม D แล้ว ไม่ใช่บั๊กด้านสิทธิ์ ให้ผู้รวมเอกสารแก้ข้อความเก่า ไม่แก้ expected ให้ตรงกับคำอ้างเก่า
2. **ไม่พบความผิดปกติของ runtime ในขอบเขตเก้าสถานการณ์นี้** ไม่ได้หมายความว่าไม่มีบั๊กทุกเงื่อนไข
3. การหมดอายุ session 24 ชั่วโมง การปลดล็อกเมื่อครบ 15 นาที การเลื่อนข้ามวันรอบขาย และเวลา expiry ของ grant ส่งให้ C7 ตรวจท้ายสุด เพื่อไม่เปลี่ยนเวลาระหว่างการสำรวจพร้อมกัน
4. C1 ตรวจข้อมูลแยกเจ้าของด้วยหนึ่งใบจากการซื้อสำเร็จ ไม่ตรวจการส่งอีเมลจริงหรือ provider สมาชิกภายนอก เพราะอยู่นอกขอบเขตระบบทดลอง
