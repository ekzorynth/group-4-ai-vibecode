## กติกากันชนและสถานะหลังจบ

C7 เริ่มหลัง C1–C6 จบตามข้อความแจ้งของผู้ควบคุม แม้ใช้ฐานข้อมูลแยกอยู่แล้ว เพื่อรักษาลำดับ closing ของบทเรียน ทุก URL ภายในสคริปต์ถูกยืนยันว่าชี้ 4347 ก่อนเริ่ม และคำสั่ง reset/clock ใช้เฉพาะโลก C7

หลังจบ reset C7 กลับข้อมูลตัวอย่างและเวลาเริ่มต้นของ C7 เท่านั้น จึงไม่มีคำสั่งซื้อหรือสิทธิ์จากการทดสอบค้างในโลกนี้ และไม่ลบหลักฐานหรือข้อมูลที่ C1–C6 สร้างไว้

## ข้อจำกัดและส่งต่อผู้ตัดสิน

- ไม่พบ runtime defect ในสถานการณ์ขอบทั้งแปด ไม่อ้างว่าทุกปัญหาเวลาหรือ race ถูกพิสูจน์แล้ว
- ขอบเวลาของสิทธิ์ตรวจด้วย clock ที่ server ทดสอบควบคุม ไม่ใช่การรอจริง 24 ชั่วโมงหรือทดสอบ timezone ของทุกอุปกรณ์
- ไม่เปลี่ยนสูตร expected ตามค่าใน implementation และไม่อ่านเฉลยบั๊กก่อนทดสอบ เหมาะใช้เป็นหลักฐาน [O] ให้ผู้ตัดสินที่แยกจากผู้สำรวจทบทวนต่อ
- Snapshot รูป General เป็นหลักฐานหน้าจอประกอบ ขอบเวลา 1ms ใช้ผล API เป็นหลัก เพราะไม่สามารถอ่านขอบระดับมิลลิวินาทีจากรูปได้
