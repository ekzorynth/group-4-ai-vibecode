# ตรวจความครอบคลุมของการทดสอบ ENCORE

ทบทวนวันที่ 6 พฤศจิกายน 2569 โดยตรวจข้อกำหนด เส้นทางซื้อบัตร จุดเปลี่ยนสถานะ ขอบเวลา และสิทธิ์ของแต่ละบัญชี แล้วเพิ่มกรณีที่ขาดจากชุดเดิม 59 ข้อ เป็น 89 ข้อ: API 61 ข้อ และหน้าจอ 28 ข้อ ผลรันล่าสุดอยู่ใน [TEST-REPORT.md](TEST-REPORT.md)

เพิ่มกรณี A45–A61 และ U16–U25 รวม 27 ข้อ โดยยืนยันทั้งผลตอบกลับและข้อมูลหลังทำรายการ เช่น ที่นั่งเดิมยังถูกจองอยู่เมื่อเปลี่ยนที่นั่งไม่ผ่าน ยอดคืนเงินไม่ซ้ำ และไม่มีตั๋วหรืออีเมลออกเมื่อชำระไม่สำเร็จ

## การจับคู่กับข้อกำหนดและภาพอ้างอิง

[TEST-PLAN.md](TEST-PLAN.md) สร้างตารางจับคู่จากผลรันจริงครอบคลุม FR 18 หมวด BR 20 หมวด และ NFR 7 หมวด โดยแต่ละกรณีมีรหัสข้อกำหนดกำกับ สคริปต์รายงานตรวจว่ามีผลครบทั้ง 89 รหัส ไม่ซ้ำและไม่ขาด จึงไม่ใช้ผลทดสอบเพียงบางส่วนมารายงานว่าผ่านทั้งหมด

[ภาพเทียบเว็บอ้างอิง](references/SCREENSHOT-COMPARISON.md) ระบุว่าแต่ละภาพเกี่ยวข้องกับขั้นตอนและข้อกำหนดใด ภาพเว็บไซต์ภายนอกใช้ประกอบการวิเคราะห์ ไม่ใช่ผลการทดสอบ ENCORE ส่วน `npm run test:references` ตรวจแหล่งที่มา SHA-256 ขนาดไฟล์ และความครบของภาพคู่

## วิธีรันซ้ำ

```sh
npm ci
npx playwright install chromium
npm run test:all
```

API ใช้พอร์ต 4311 และ UI ใช้ 4312 พร้อมฐานข้อมูลในหน่วยความจำแยกจากเว็บใช้งาน พอร์ต 4314 ใช้ทดสอบฐานข้อมูลชั่วคราวและการอัปเกรด ทั้งหมดตั้งเวลาก่อนแต่ละกรณีด้วยเครื่องมือทดสอบที่ต้องมีโทเคน ไม่ล้างฐานข้อมูล Docker ที่พอร์ต 4310

Docker smoke ทดสอบด้วย image สำหรับใช้งานจริง พอร์ต 4315 และ project/volume ชั่วคราวแยกต่างหาก ตรวจซื้อบัตร รับ QR/อีเมล ปิดเครื่องมือทดสอบ และเก็บคำสั่งซื้อ/บัตร/อีเมลเดิมหลัง restart และสร้าง container ใหม่ ดู [DOCKER-VERIFICATION.md](DOCKER-VERIFICATION.md)

## ขอบเขตที่ยังไม่ยืนยัน

ผลนี้ครอบคลุมการทดสอบยอมรับอัตโนมัติและการทบทวนโดยผู้พัฒนา ไม่ครอบคลุมการรับรองผู้ให้บริการภายนอก การทดสอบโหลด หรือเปอร์เซ็นต์ความครอบคลุมของทุกบรรทัดและเงื่อนไขในโค้ด

ยังไม่ทดสอบผู้ใช้พร้อมกันระดับงานจริง การเชื่อมสมาชิก/ผู้รับชำระ/อีเมลภายนอก กล้องสแกน QR การเข้าถึงตาม WCAG แบบครบถ้วน Safari/Firefox ระบบปฏิบัติการทุกแบบ หรือเหตุการณ์เครื่องดับ/พื้นที่ดิสก์เต็มทุกจังหวะ กรณีทดสอบพร้อมกันสองคำขอพิสูจน์ข้อกำหนดในตัวอย่างนี้ แต่ไม่ใช้แทนผลทดสอบรองรับโหลดจริง
